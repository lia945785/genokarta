# Тестові файли ДНК

Тут лежать файли для ручної перевірки сторінки «Завантаження файлу». Вони не пов'язані з демо-файлом (`public/demo-genome.txt`).

Усі файли згенеровано штучно, це не дані реальної людини. Коректні файли містять 38 маркерів, на яких будується звіт (наприклад, `rs429358` і `rs7412` для хвороби Альцгеймера), а також випадкові маркери-заповнювачі.

Як користуватися: відкрийте застосунок (`npm run dev`) → «Завантажити файл ДНК» → перетягніть файл у зону завантаження або натисніть «Обрати файл».

## Коректні файли: мають прийматися

Перевіряємо, що система розпізнає всі чотири підтримувані формати.

| Файл | Що перевіряє | Очікуваний результат |
|---|---|---|
| `valid-23andme.txt` | Формат 23andMe, коментарі `#`, службові маркери `i…`, хромосоми X і MT | Прийнято: 23andMe, 122 маркери |
| `valid-ancestry.txt` | Формат AncestryDNA з окремими алелями, віндовські кінці рядків (CRLF) | Прийнято: AncestryDNA, 120 маркерів |
| `valid-myheritage.csv` | Формат MyHeritage: CSV, значення в лапках | Прийнято: MyHeritage, 120 маркерів |
| `valid-sample.vcf` | Формат VCF 4.2 з метаданими `##` | Прийнято: VCF, 60 маркерів |

## Некоректні файли: мають відхилятися

Кожен файл перевіряє одне окреме правило цілісності.

| Файл | Що не так | Очікуване повідомлення |
|---|---|---|
| `invalid-empty.txt` | Файл порожній (0 байт) | «Файл порожній. Оберіть інший файл.» |
| `invalid-extension.json` | Непідтримуване розширення | «Файл … має непідтримуваний формат. Завантажте файл .txt, .csv, .tsv або .vcf.» |
| `invalid-content.txt` | Звичайний текст, а не генотип | «Не вдалося розпізнати вміст…» |
| `invalid-missing-genotype.txt` | Схожий на 23andMe, але в рядках немає колонки з генотипом | «Не вдалося розпізнати вміст…» |
| `invalid-headers-only.csv` | Заголовок MyHeritage є, а маркерів немає | «У файлі не знайдено жодного маркера.» |

## Файл, більший за 50 МБ

Такий файл не зберігається в репозиторії, бо він завеликий. Його можна створити в PowerShell, з кореня проєкту: команда робить файл розміром 50 МБ + 1 байт.

```powershell
$f = [IO.File]::Create("$PWD\test-files\invalid-too-large.txt"); $f.SetLength(52428801); $f.Close()
```

Очікуване повідомлення: «Файл більший за 50 МБ…». Після перевірки файл можна видалити.

## Автоматична перевірка

Тест `src/domain/testFiles.test.ts` проганяє кожен файл із цієї теки через ту саму функцію перевірки, що й сторінка завантаження, і порівнює результат із таблицями вище. Запуск: `npm test`.
